# Himawari ドキュメント 🌻

> **下書きです。日本語のネイティブによる確認が必要です。** (Draft, needs native review.) 英語版が正式な内容です。

Himawari は、ビジュアルノベルを作るためのエンジンです。物語を書いて、書きながら遊んで、ダブルクリックで始まる小さな Windows ゲームとして配布できます。

- **コードは書かなくて大丈夫。** Himawari Studio では、ボタンやフォームだけですべての作業ができます。
- **コードを書く人も歓迎。** 同じプロジェクトが、ふつうのテキストファイル、コマンドライン、git でも扱えます。
- **どの Windows PC でも軽く動く。** ゲームは Windows 10 / 11 向けの小さなネイティブプログラムです。
- **AI は使うかどうか自由。** 使わなくても、まったく困りません。
