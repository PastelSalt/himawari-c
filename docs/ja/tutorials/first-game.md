# はじめてのゲームを作る

> **下書きです。日本語のネイティブによる確認が必要です。** (Draft, needs native review.) 英語版: [Make your first game](../../tutorials/first-game.md)

約 15 分で、Himawari Studio で選択肢のある小さな物語を書き、書きながら遊び、友だちに送れるゲームにします。**コードは一行も書きません。** ボタンとフォームだけで進められます。

必要なのは、Windows 10 / 11 の PC に入れた Himawari Studio だけです。絵や音は用意しなくても大丈夫です。自分の素材を追加するまでは、名前つきの仮素材が表示されます。

## 1. 新しいプロジェクトを作る
1. Studio を開き、ようこそ画面で **新規プロジェクト** を選びます。
2. **ゲームの名前** を入力します。例：「はじめての物語」
3. **作成する場所** の **選択…** を押して、ゲームを入れるフォルダーを選びます。
4. **テンプレート** は **クラシック ADV（テキストボックス）** を選びます。キャラクター、選択肢、仮の絵が入った、すぐ遊べるシーンなので、まずは書き換えるところから始められます。
5. **言語** の **執筆する言語** は、そのままご自分の言語にします。（2 つ目の言語を追加するまで、翻訳ツールは表示されません。）
6. **プロジェクトを作成** を押します。

プロジェクトが開き、**台本** ビューに物語、その隣の **プレビュー** にゲームが表示されます。

> まず案内つきで見たい場合は、ようこそ画面の **チュートリアルを開く** を選んでください。

## 2. 台詞を変えて、ゲームを見る
1. 左のシーン一覧から、はじめから入っているシーンを開きます。
2. 台本の台詞をクリックして、言葉を書き換えます。
3. プレビューを見てください。入力に合わせて更新され、さっきの場面の続きから遊べます。

これがいつもの流れです。**書く、ちらっと見る、また書く。**

## 3. 台詞を足す
シーンの最後の行の下に、いろいろなものを足すボタンがあります。試してみましょう。
- **台詞**：誰かが話します。**話し手** を選んで、**台詞を入力…** に書きます。
- **ナレーション**：話し手のいない文章です。
- **背景**：キャラクターの後ろに出す絵を選びます。
- **キャラクターを表示**：登場させます。表情は **表情や属性を追加** で足せます。
- **BGM** と **効果音**：音を選びます。ファイルがまだなくても、ゲームは無音になるだけで問題ありません。

行は **ドラッグ** で移動でき、**複製** や **削除** もできます。まちがえても、**履歴** から元に戻せます。

## 4. 選択肢を作る
1. **選択肢** を選びます。
2. プレイヤーに見せる質問を入力します。
3. 選択肢の言葉を書きます。増やすときは **選択肢を追加** を使います。
4. 各選択肢の下に、そのあとの台詞を足します。別のシーンへ進めるなら **シーンへ移動**、物語を終えるなら **おわり** を使います。

プレビューで、どちらの選択肢も押して遊んでみてください。

## 5. キャラクターを追加する
1. **キャラクター** を開き、**新しいキャラクター** を選びます。
2. 名前を付けます。ほかの項目は、書きたいぶんだけで大丈夫です。
3. シーンに戻ると、**話し手** の一覧に表示されています。

## 6. 自分の絵や音を入れる（準備ができたら）
この手順は飛ばしても大丈夫です。書いている間は仮素材のままで困りません。

絵や音ができたら **素材** を開き、**ファイルを追加…** で選びます。シーンで使う絵がまだないときは、**仮の素材を作る** で名前と色から仮素材を作れます。あとから同じ名前のファイルに差し替えられます。

## 7. すべてのルートを確かめる
**ストーリーグラフ** を開いて **全ルートをテストプレイ** を押します。Studio がすべてのルートを数秒で遊び、いくつのエンディングに着いたか、プレイヤーが決して見られない場所がないかを教えてくれます。指摘された点は **問題** パネルで直します。やさしい言葉の説明と直し方つきで表示されます。

## 8. ゲームを配る
1. **ビルドと書き出し** を開きます。
2. **Windows 用ゲーム（x64）** で **フォルダー** か **zip ファイル** を選びます。
3. **ゲームを書き出す** を押し、**エクスプローラーで表示** を押します。
4. zip を友だちに送ります。解凍して、**ゲームの `.exe` をダブルクリック** するだけで遊べます。インストールは不要です。

くわしくは [Export a game](../../how-to/export-a-game.md)（英語）をご覧ください。
