# assets/

Put your art and sound here. Anything a script names but can't find is shown as a labeled placeholder, so you can write first and add files later.

| Folder | Used by | Example |
|---|---|---|
| `bg/` | `bg school_gate` | `bg/school_gate.png` |
| `cg/` | `cg sunset_kiss` | `cg/sunset_kiss.png` |
| `sprites/<character>/<group>/` | layered characters | `sprites/aoi/eyes/smile.png` |
| `music/`, `sfx/`, `ambient/` | `music theme`, `sfx bell` | `music/theme.ogg` |
| `voice/<language>/` | voiced lines, by line ID | `voice/en/k3f9a1.ogg` |
| `rules/` | `with rule(wipe_left, 500)` | `rules/wipe_left.png` |
| `fonts/` | `himawari.json` → `fonts` | `fonts/NotoSansJP-Regular.otf` |

Himawari never generates art, music, or voices. Everything here comes from you.
